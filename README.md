# CENTR-B Security Academy — React

Многостраничный адаптивный сайт учебного центра на React + Vite.

## Запуск локально

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Страницы

- `/` — главная
- `/courses` — каталог программ
- `/courses/:slug` — страница программы
- `/prices` — цены
- `/schedule` — расписание
- `/about` — о центре
- `/documents` — сведения и документы
- `/news` — новости
- `/contacts` — контакты и форма заявки

## Важно перед публикацией

- Форма заявки сейчас подготавливает письмо через `mailto:`. Для полноценной отправки без почтового клиента подключите серверный endpoint или CRM.
- В разделе «Документы» ссылки ведут на официальный раздел исходного сайта; замените их на прямые ссылки на актуальные файлы после проверки.
- Фото загружаются с Unsplash по внешним URL. Для production рекомендуется использовать согласованные фотографии центра и хранить их локально.
- Проверьте расписание, стоимость, реквизиты и правовые сведения перед публикацией.
- Добавьте актуальную политику обработки персональных данных и согласие на обработку персональных данных, если форма будет собирать заявки.
